# José Orlando | Portfolio

Personal portfolio of **José Orlando Vieira Xavier**: Systems Analysis and Development student (CEUB) and Commercial Analyst building automations and AI-assisted tools.

🔗 **Live site:** https://joseorlando-vx.github.io/Portfolio/

## What is on the site

- Selected projects (proposal generator, collections agent, webhook proxy) with problem, solution and stack
- Experience, education and certifications
- Skills, labeled as "in practice" or "learning", each linked to evidence
- English by default, with a Portuguese toggle

## Stack

Plain HTML and CSS plus a few lines of JavaScript for the language toggle. No build step. Hosted on GitHub Pages.

## Run locally

```bash
python -m http.server 8000
# open http://localhost:8000
```
